# Handoff：ワンド・ソード数札の交差構図化（A案）

作成日：2026-09-30
対象：Caelum Liber Arcanorum ／ `tools/tarot-gen/layout.py`
前提：`tarot-gen-instructions.md`、`tarot-gen-minor-addendum.md` の仕様・禁止事項をすべて引き継ぐ。
**本書は `handoff-pips-layout-fix.md`（前回の修正案）を置き換える。** 前回導入した後光（glow）・拡大率・y_offset は、ワンドとソードでは廃止する。

---

## 1. 背景と方針

前回の修正（拡大・後光・下方向へのずらし）では、次の問題が解消しなかった。
- 後光が流れ星の尾のように見え、画面が霞む。
- 細長い記号が格子状にばらばらに浮き、装飾として見えない。
- 記号が光背の円の縁や花の装飾をまたいでいる。

そこで、ワンドとソードは**マルセイユ版に着想を得た交差構図**に切り替える。記号同士を組み合わせて一つの図形にし、**光背の円の内側に完全に収める**。

- **カップとペンタクルは対象外。** 出力が修正前と完全に一致することを確認すること。
- 伝統的な版の図案を忠実に複製する必要はない。以下の規則で生成される構図を正とする。

## 2. 準備

### 2.1 光背の円の計測

- ワンドとソードの背景（`assets/bg_wands.png`、`assets/bg_swords.png`）から、光背の円の中心 (cx, cy) と半径 R を計測する。
- 計測値を `layout_config.json` に保存する。自動検出が不安定な場合は、目視で調整した値を記入してよい。
- **配置可能領域**は、半径 0.90R の円の内側とする。

### 2.2 素材の追加・再生成（AI生成、各3案→人が選定）

| ファイル | 内容 | 備考 |
|---|---|---|
| `assets/symbol_swords_curved.png` | ゆるやかに湾曲した片刃のサーベル。金の柄。先端を上に、刃は右側へ弧を描く | 新規。左側用は左右反転して使う |
| `assets/symbol_swords.png` | 既存の直剣 | そのまま使用（奇数枚の中央用） |
| `assets/symbol_wands_long.png` | 細長くまっすぐな木の杖。両端に小さな若葉。金の金具 | 新規。縦横比 1:12 程度 |
| `assets/rosette.png` | 小さな金の百合の花飾り（交差点に置く装飾） | 新規。任意だが推奨 |

プロンプトは addendum §2.1 の形式に従い、`[ASSET]` 部分のみ上表の内容に差し替える。背景は透過、または緑背景からクロマキーで抜く。

## 3. 構図の規則

以下、長さや位置は R を単位とし、(cx, cy) を原点とする。

### 3.1 ソード：紡錘形（ヴェシカ）構図

- **湾曲剣の組**：左右一対の湾曲剣で、上端 (0, −0.80R) と下端 (0, +0.80R) を結ぶ紡錘形を作る。
  - 右側は素材のまま、左側は左右反転した素材を使う。
  - 剣の柄は下、切っ先は上とする。上端で切っ先同士が交わる。
- **組の数**：`floor(n / 2)` 組。複数組は**入れ子状**に重ね、外側ほど膨らみを大きくする。
  - 膨らみ幅（中心線から弧の頂点までの距離）は、内側 0.20R から外側 0.80R まで等間隔に割り付ける。
  - 素材の湾曲を膨らみ幅に合わせるため、横方向のみの拡大縮小を許可する（縦横比の変化は ±30% 以内）。
- **奇数枚**：中央に直剣を1本、垂直に配置する（長さ 1.40R）。
- **交差点**：上端と下端の交点に、花飾りを置く（大きさ 0.14R）。
- 組同士の弧が近すぎる場合（最小間隔 0.08R 未満）は、刃の太さを自動で細くし、それでも足りなければ警告を出す。

### 3.2 ワンド：斜め格子構図

- **斜めの杖**：右上がり（垂直から +20°）の杖を `floor(n / 2)` 本、左上がり（−20°）の杖を同数配置する。
  - 同じ向きの杖同士の横方向の間隔は 0.30R とし、全体を中心に揃える。
  - 両方向の杖が交差して菱形の格子ができる。
- **奇数枚**：中央に垂直の杖を1本追加する。
- **長さ**：各杖は、配置可能領域（0.90R の円）の内側に両端が収まる最大の長さとし、端から 0.05R の余白を取る。
- **交差点**：斜めの杖同士の交点のうち、配置可能領域の内側にあるものすべてに花飾りを置く（大きさ 0.10R）。交点が多すぎて煩雑な場合は、中央列の交点のみに限定する設定を用意すること。

### 3.3 共通の描画仕様

- 後光（glow）は使わない。
- 各記号に、細い輪郭線（濃紺 #0F1E3A、幅2px、不透明度60%）と、既存のごく薄いドロップシャドウを付ける。
- 描画順：背景 → ドロップシャドウ → 記号（奥の組から手前の組へ）→ 花飾り
- ワンドの明度補正（明度+15%、彩度+10%）は維持する。
- 記号の角度はカードの向きに対して固定とし、乱数で揺らさない（全カードで再現性を保つ）。

## 4. 検証

- **個数**：記号の本数が数字と一致すること（花飾りは数えない）。自動テストで検証する。
- **領域**：すべての記号・花飾りの外接範囲が、配置可能領域（0.90R の円）の内側に収まること。
- **切り抜き**：既存の検証（すべての要素の下端が y=0.89 以内）も維持する。
- **不変性**：カップとペンタクルの出力が、修正前とバイト単位で一致すること。

## 5. 作業手順

1. §2 の計測と素材生成を行い、素材の候補をコンタクトシートにして**作業を止め、報告する**。
2. 総司が素材を選定したら、§3 を実装する。
3. **試験出力**：ソードとワンドの「2・3・7・10」の計8枚のみを出力する。
4. 8枚をフレームと合成し、`out/review/pips_crossed_preview.png`（2行×4列、上段ソード・下段ワンド）を出力して**作業を止め、報告する**。
5. 総司の承認後、ワンドとソードの残り10枚を出力し、`composite.py` で合成、スート別コンタクトシートを再出力する。
