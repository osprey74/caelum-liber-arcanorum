# Handoff：数札レイアウトの視認性修正（layout.py）

作成日：2026-09-30
対象：Caelum Liber Arcanorum ／ `tools/tarot-gen/layout.py`
前提：`tarot-gen-instructions.md` と `tarot-gen-minor-addendum.md` の仕様・禁止事項をすべて引き継ぐ。

---

## 1. 背景

数札36枚（2〜10 × 4スート）を出力し、フレームと合成して確認した結果は次のとおり。

| スート | 判定 | 課題 |
|---|---|---|
| カップ | 採用 | なし |
| ペンタクル | 採用 | なし |
| ワンド | 要修正 | 杖が細く小さい／茶色で背景とのコントラスト不足／上段が太陽の装飾と重なる |
| ソード | 要修正 | 剣が細く小さい／背景に埋もれる |

- 記号の個数、下端の切り抜き（約8.9%）、アーチ窓の角による欠けは、全36枚で問題なし。
- **記号素材（`assets/symbol_*.png`）と背景（`assets/bg_*.png`）は作り直さない。** 今回は `layout.py` の設定変更のみで対応する。
- **カップとペンタクルの出力結果は変更しないこと。** 修正後に再出力し、修正前との差分がゼロであることを確認する。

## 2. 修正内容

### 2.1 スート別設定の導入

`layout.py` にスート別の設定テーブルを追加し、既存の固定値を置き換える。

```python
SUIT_CONFIG = {
    "wands":     {"scale": 1.25, "glow": True,  "y_offset": 0.04, "brighten": True},
    "swords":    {"scale": 1.25, "glow": True,  "y_offset": 0.00, "brighten": False},
    "cups":      {"scale": 1.00, "glow": False, "y_offset": 0.00, "brighten": False},
    "pentacles": {"scale": 1.00, "glow": False, "y_offset": 0.00, "brighten": False},
}
```

- 値はコマンドライン引数または設定ファイル（例：`layout_config.json`）で上書きできるようにすること。微調整を繰り返すため。

### 2.2 記号の拡大（scale）

- 既存の大きさ（2〜3枚：0.26、4〜6枚：0.20、7〜10枚：0.15）に `scale` を掛ける。
- 既存の重なり回避処理（重なる場合は5%ずつ縮小）は、拡大後の大きさに対して適用する。

### 2.3 後光（glow）

`glow: True` のスートでは、記号の背後に次の光を敷く。

- **作り方**：記号のアルファ（透過）マスクを膨張させ、ぼかす。
- **色**：アイボリー（#F3E9D2 前後）
- **ぼかし半径**：12px 前後（1024×1536 基準）
- **不透明度**：35%（30〜40% の範囲で調整可能にする）
- **描画順**：背景 → 後光 → 既存のドロップシャドウ → 記号

### 2.4 明度補正（brighten）

`brighten: True` のスート（ワンド）では、配置前に記号素材を補正する。

- 明度 +15%、彩度 +10%
- 素材ファイル自体は上書きせず、メモリ上で補正すること。

### 2.5 縦位置の補正（y_offset）

- 全配置座標の y に `y_offset` を加算する（ワンド：+0.04）。背景上部の太陽の装飾を避けるため。
- 加算後も既存の検証（**すべての記号の下端が y=0.89 以内**）を必ず実行し、違反時は警告を出す。違反する場合は、そのカードのみ scale を自動で 5% ずつ縮小して再検証すること。

## 3. 作業手順

1. `SUIT_CONFIG` と 2.2〜2.5 を実装する。
2. **試験出力**：ワンドとソードの「7」と「10」の計4枚のみを出力する（`--only` で指定）。
3. 4枚をフレームと合成し、比較画像（修正前・修正後を左右に並べたもの）を `out/review/pips_fix_compare.png` に出力して**作業を止め、報告する**。
4. 総司の承認後、ワンドとソードの残り14枚を出力する。
5. `composite.py` で18枚を合成し、スート別コンタクトシートを再出力する。
