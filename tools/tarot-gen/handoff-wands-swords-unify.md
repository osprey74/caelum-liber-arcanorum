# Handoff：ソードの拡大と、ワンドをソードと同じ組み方に統一

作成日：2026-09-30
対象：Caelum Liber Arcanorum ／ `tools/tarot-gen/layout.py`（ワンド・ソード）
前提：これまでのソードの仕様（`handoff-swords-trace.md` と、その後の「刃のみ横方向に太くする」方式）を引き継ぐ。**本書の内容が優先する。**

---

## 1. 背景

- カップとペンタクルの記号は、光背の円からはみ出して配置されている。総司はこれを了承している。
- 一方、ワンドとソードには「半径0.90R（のちに0.96R）の円の内側に収める」制約を課していた。これは A案の handoff で、当時の格子配置の見栄えの問題に対処するために設けたものである。スート間で基準が不統一になっていた。
- 総司の指示は次の2点。
  1. ソードも円からのはみ出しを許容し、**記号をもっと大きくする**。
  2. ワンドも、縦に並べる構図ではなく、**ソードと同じ組み方（ラフのトレース構図）**にする。

## 2. 配置制約の変更（ワンド・ソード）

- **光背の円による制約（0.90R／0.96R）を廃止する。** 許容リストも不要になるため削除する。
- 代わりに、全スート共通の次の制約のみとする。
  - フレーム合成後に見えるアーチ窓の内側に、全要素が収まること（窓の縁から 0.02R 以上の余白）。
  - 下端 y=0.89 の検証（合成時の切り抜き対策）。
- 記号が光背の円の縁や背景の装飾に重なることは許容する。

## 3. 大きさの基準：カップ・ペンタクルにそろえる

- 枚数 n ごとに、**カップの同じ枚数のカードの記号群の外接矩形**（全記号を囲む最小の矩形）を計算する。
- ソードとワンドは、`swords_traced.json` の配置を**縦横同率で一律に拡大**し、記号群の外接矩形の**高さ**が、カップの同じ枚数の外接矩形の高さと一致するようにする。
- 拡大後、外接矩形の**幅**がカップの幅の1.15倍を超える場合は、幅が1.15倍になるまで拡大率を下げる。
- 拡大の中心は、光背の円の中心とする。
- 拡大後に §2 の制約に違反する場合は、違反しなくなるまで拡大率を下げ、その値を報告する。
- 各枚数の拡大率を一覧にして報告すること。

## 4. ソードの描画

- 配置は `swords_traced.json` を §3 の拡大率で拡大したものを使う。
- 「剣全体は長さに合わせて縦横同率、刃のみ横方向に太くする」方式は維持する。刃の幅の基準は、**拡大後の4の剣**とする。
- 刃の縦横比の上限（+100%）と、刃の幅が鍔の70%を超える場合の警告は維持する。

## 5. ワンドの描画（ソードと同じ組み方に変更）

- A案の斜め格子構図は廃止する。
- **配置はソードと同じ `swords_traced.json` を使う**（同じ枚数では、ソードとワンドの配置の骨格が一致する）。拡大率は、ワンドについても §3 の手順で求める。
- 対応関係：剣の柄頭 → 杖の下端、剣の切っ先 → 杖の上端。奇数枚の縦の剣 → 縦の杖。
- 素材は `assets/symbol_wands_long.png`（細長い杖）を使う。
- **杖の太さ**：
  - 杖全体を長さに合わせて縦横同率に縮める。
  - そのうえで、両端の若葉の飾りを除いた「軸」の部分だけを横方向に太くし、拡大後の4の杖の軸の幅にそろえる。
  - 若葉の飾りは変形させない（ソードで柄を変形させないのと同じ考え方）。
  - 軸の横方向の拡大の上限は +100% とし、超える場合は警告する。
- 花飾り（`rosette.png`）は使わない。
- ワンドの明度補正（明度+15%、彩度+10%）は維持する。

## 6. 変更しないもの

- カップとペンタクルの出力は変更しない（バイト単位で一致すること）。
- 輪郭線・ドロップシャドウ・描画順の共通仕様。

## 7. 作業手順

1. §2〜§5 を実装する。
2. **試験出力**：ワンドとソードの「2・4・7・10」の計8枚を出力する。
3. 比較画像 `out/review/suits_size_compare.png` を出力する。
   - 3行×4列（上段カップ、中段ソード、下段ワンド）とし、列は枚数 2・4・7・10 とする。
   - フレーム合成後の状態で並べる。
4. §3 の拡大率の一覧とあわせて、**作業を止め、報告する**。
5. 総司の承認後、ワンドとソードの残りの枚数を出力し、合成する。
6. 4スートのコンタクトシートを、**確定版のファイルから**作り直す。
   - 前回の一覧では、ワンド・ソードの数札が修正前の古い版になっていた。その原因（参照していたファイルの場所など）も報告すること。

## 8. 完了条件

- [ ] ワンドがソードと同じ組み方になり、杖の若葉の飾りが歪んでいないこと
- [ ] §2 の制約と個数の自動テストがすべて通ること
- [ ] カップ・ペンタクルの出力が修正前とバイト単位で一致すること
- [ ] 4スートのコンタクトシートが確定版で作り直されていること
- [ ] 拡大率などの最終値を `layout_config.json` と README に記載すること
