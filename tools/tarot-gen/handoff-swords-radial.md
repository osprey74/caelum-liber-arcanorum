# Handoff：ソード数札の放射状交差構図

作成日：2026-09-30
対象：Caelum Liber Arcanorum ／ `tools/tarot-gen/layout.py`（ソードのみ）
前提：`handoff-pips-crossed-layout.md`（A案）の仕様を引き継ぐ。
**本書は A案 §3.1 と `handoff-swords-fix.md` のソードの規則をすべて置き換える。** 紡錘形（湾曲剣）の構図は廃止する。
ワンド・カップ・ペンタクルは変更しない。

---

## 1. 背景と方針

- 紡錘形の構図では、ソードの10の中央部で柄が密集する問題が解消しなかった。
- そこで、**すべて直剣で構成し、円の中心で交差させる放射状の構図**に切り替える。
  - 奇数枚：中央に縦の剣を1本置く。
  - 残りの剣：左右対称の2本1組とし、X字に交差させる。
- 総司の指定により、**全体は縦長にまとめる**（最大傾き 40°）。

## 2. 素材

- 使用するのは既存の直剣 `assets/symbol_swords.png` と花飾り `assets/rosette.png` のみ。
- `symbol_swords_curved.png` は使用しない（ファイルは削除せず残す）。
- 新規の素材生成は行わない。

## 3. 構図の規則

以下、長さや位置は光背の円の半径 R を単位とし、円の中心 (cx, cy) を原点とする。角度は垂直からの傾きで、右回りを正とする。

### 3.1 剣の向きと位置

- すべての剣は、刃の中心線が**円の中心を通る**直線上に置く。
- 向きは切っ先が上、柄が下とする。傾き +θ の剣は切っ先が右上・柄が左下、−θ の剣は切っ先が左上・柄が右下になる。
- **長さ**：1.56R（切っ先から柄頭まで）。

### 3.2 枚数別の角度表

表の「±」は、+θ と −θ の2本1組を表す。

| 枚数 | 縦の剣（0°） | 交差の組（±θ） |
|---|---|---|
| 2 | なし | ±16° |
| 3 | あり | ±18° |
| 4 | なし | ±12°、±28° |
| 5 | あり | ±16°、±32° |
| 6 | なし | ±10°、±24°、±38° |
| 7 | あり | ±13°、±26°、±39° |
| 8 | なし | ±8°、±18°、±29°、±40° |
| 9 | あり | ±10°、±20°、±30°、±40° |
| 10 | なし | ±6°、±14°、±23°、±32°、±40° |

- 角度表は `layout_config.json` に保存し、調整できるようにすること。

### 3.3 鍔の段違い配置

角度差が小さい剣同士は鍔（柄の横棒）がぶつかりやすいため、鍔の高さを段違いにする。

- 全剣を角度の順に並べ、**1本おきに軸方向へずらす**。
  - 偶数番目：軸方向に −0.07R（全体を切っ先側へ）
  - 奇数番目：軸方向に +0.07R（全体を柄側へ）
- 軸方向にずらしても、刃の中心線は円の中心を通ったままとなる。
- 縦の剣（0°）は、ずらさない。
- ずらした後も、隣り合う柄（鍔を含む）の間隔が 0.05R 未満になる場合は警告を出す。

### 3.4 中心の花飾り

- 円の中心に花飾りを置く（大きさ 0.16R）。全刃の交点を覆い、羅針盤の中心のように見せる。
- 上端・下端の花飾り（紡錘形用）は廃止する。

### 3.5 描画順

1. 背景
2. ドロップシャドウ
3. 剣：傾きの大きい組から小さい組の順に描く。同じ組の中では、組ごとに左右どちらを上にするかを交互に切り替える（編み込みのような重なりにする）
4. 縦の剣（0°）
5. 中心の花飾り

### 3.6 維持する仕様

- 配置可能領域（半径 0.90R の円の内側）に、全要素の外接範囲が収まること。
- 下端 y=0.89 の検証、個数の自動テスト（花飾りは数えない）。
- 輪郭線（濃紺 #0F1E3A、幅2px、不透明度60%）とドロップシャドウ。後光は使わない。
- 角度は固定とし、乱数で揺らさない。

## 4. 作業手順

1. §3 を実装する。
2. **試験出力**：ソードの「2・3・4・7・9・10」の計6枚を出力する。
3. 6枚をフレームと合成し、`out/review/swords_radial_preview.png`（1行×6列）に出力する。あわせて、各カードの光背の円の部分を拡大した画像を `out/review/swords_radial_zoom.png` に出力する。ここで**作業を止め、報告する**。
4. 総司の承認後、ソードの残り3枚（5・6・8）を出力し、`composite.py` で合成、ソードのコンタクトシートを再出力する。
